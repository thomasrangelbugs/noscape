# Stealth Ops

Stealth Ops é um jogo web de ação furtiva com fases procedurais, onde cada partida gera uma nova operação. O projeto combina mecânicas de stealth, movimentação tática, controle de barulho, visibilidade, uso de iscas, armas, ranking local e diferentes modos de jogo.

## Funcionalidades

* Jogo stealth diretamente no navegador
* Fases geradas proceduralmente
* Sistema de seed para geração de runs
* Modos de operação com diferentes cenários
* Seleção de personagens
* Modo campanha e modo survivor
* Sistema de pontuação
* Ranking local
* Conquistas
* Controle de visibilidade e barulho
* Mecânica de correr, agachar, atacar, recarregar e usar isca
* Arsenal inicial
* Configuração de dificuldade
* Configurações de áudio, HUD, contraste e qualidade visual
* Controles para teclado
* Controles touch para celular
* Suporte a modo paisagem em dispositivos móveis
* Interface responsiva

## Objetivo

O objetivo do projeto é criar uma experiência de jogo stealth simples, dinâmica e rejogável, explorando lógica de movimentação, colisão, geração procedural, interface de jogo, HUD, ranking local e adaptação para diferentes dispositivos.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Netlify
